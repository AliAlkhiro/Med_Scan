# 5.2 Add File Upload for Attachments Execution Report

Status: Done

## Summary

Implemented admin-side Supabase Storage uploads for attachment files.

## Implemented

- Added an attachment upload helper that writes files to the private `attachments` storage bucket.
- Restricted client-side uploads to the configured MVP MIME types: PDF, common web images, MP4, WebM, and QuickTime video.
- Generated storage-safe object paths for uploaded files.
- Added per-attachment file upload controls in the admin product form.
- Populated attachment metadata after upload: storage path, MIME type, file size, and inferred attachment type.
- Kept public product responses unchanged, so attachments remain metadata-only until the public opening flow is implemented.

## Verification

- Ran `npm run lint`.
- Ran `npm run build`.

## Notes

- Uploads require an authenticated admin that passes the existing Supabase Storage RLS policy.
- Public attachment opening, signed URL generation, and `attachment_opened` metrics remain in Milestone 5.3.
